# Grant Tracker Phase 2

Phase 1 merged Grant STW into the Grants dashboard.

Phase 2 connects the tracker to live HPG Workspace data:

- live `ngos`
- live `grant_opportunities`
- live `grant_applications`
- Development work items

The tracker now has a path from match scoring into actionable work:

`NGO + Opportunity Match → Draft Proposal → Grant Application Record → Development Work Item`

This is the first step toward making the Development grant tracker operational rather than just informational.
