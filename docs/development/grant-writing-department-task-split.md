# Grant Writing Department Task Split

This phase makes the Development grant tracker operational across HPG departments.

## Before

A strong grant match could create one Development work item and one grant application record.

## Now

A strong grant match creates a complete grant-writing task package:

1. Master Development grant package item
2. Development research task
3. Finance budget package task
4. Communications proposal narrative task
5. NGO Coordination document/questionnaire follow-up task
6. Linked grant application record

## Department responsibilities

### Development

- Needs statement research
- Demographics and statistics
- Program alignment and outcomes
- Evidence/data points for the proposal narrative

### Finance

- Project budget
- Allowable cost review
- Fiscal sponsor/admin cost assumptions
- Budget narrative

### Communications

- LOI language
- Mission, vision, and organizational background
- Proposal story and impact framing
- Funder-facing polish

### NGO Coordination

- NGO questionnaire follow-up
- Missing documents
- Project contact and program details
- Compliance/evidence packet materials

## Resulting workflow

`Live NGO + live grant opportunity -> match score -> draft proposal -> master grant package -> department tasks -> linked grant application record`

This aligns the app with HPG's real grant-writing process instead of leaving grant tracking as a standalone dashboard.
