# Form Submission Confirmation

When a staff form is submitted, the app now waits until the work item is created or updated and the form submission is saved before showing a success confirmation.

Expected behavior:

1. User fills out a form.
2. User clicks Submit.
3. Required fields are validated.
4. The mapped work item is created or updated.
5. The form submission record is saved.
6. A success confirmation appears.
7. The form sheet closes so the dropdown/sheet disappears.

Draft saves also show a confirmation, but do not use the work-item success wording.
