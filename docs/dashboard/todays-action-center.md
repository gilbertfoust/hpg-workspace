# Dashboard Phase 2: Today's Action Center

This phase turns the dashboard from a status view into an action view.

## Purpose

The dashboard should not only show charts. It should tell staff and leadership what needs attention right now.

## Action categories

The Action Center surfaces active work items that match any of these conditions:

- Overdue
- Due this week
- High priority
- Waiting on NGO
- Missing evidence
- Unassigned

## Dashboard output

The panel includes:

- summary counts for each action category
- a prioritized table of work items needing attention
- title, NGO, department, status, due date, and reasons
- quick link to the full work queue

## Why this matters

The NGO portfolio pie chart shows where HPG stands across the portfolio. The Action Center shows what HPG needs to handle next.

Together, they make the dashboard a command center instead of a template dashboard.
