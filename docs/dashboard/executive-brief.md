# Dashboard Phase 7: Executive Brief

This phase adds a plain-language command summary to the dashboard.

## Purpose

The dashboard should not require leaders to interpret every chart before understanding the current situation. The executive brief summarizes the dashboard in direct operational language.

## What it summarizes

- NGO portfolio count for the current view
- Combined attention count
- Overdue items
- Items due this week
- Missing evidence
- At-risk NGO records
- Data readiness
- Live data sources
- Missing data sources
- Busiest department by visible workload

## Placement

The Executive Brief appears after Dashboard Filters and Drilldowns, before KPI cards. This makes it the first interpretive layer of the dashboard.

## Value

This gives board members, department heads, coordinators, and operators a quick command readout before they move into charts, tasks, and detailed sections.
