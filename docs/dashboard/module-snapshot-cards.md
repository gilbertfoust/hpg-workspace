# Dashboard Phase 3: Module Snapshot Cards

This phase adds live module health cards to the dashboard.

## Purpose

The dashboard should show the current status of each major workspace area even when a hub is still being built.

## Snapshot areas

- NGO Coordination
- Development / Grants
- Finance
- HR
- Documents / Forms
- Compliance

## Each card shows

- current status: Connected, Needs Attention, In Build, or Needs Build
- live counts where tables are available
- warnings when schema/tables are not connected yet
- quick link into the related hub

## Why this matters

This gives leadership a practical command view:

- what is working
- what has live records
- what needs attention
- what still needs schema/build work

This phase makes the dashboard useful before every hub is complete.
